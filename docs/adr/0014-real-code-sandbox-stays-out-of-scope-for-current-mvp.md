# 当前 MVP 不接入真实代码执行沙箱

已评估站内运行 C++ 的必要性：当前阶段继续不接入真实代码执行沙箱。

原因：

- 产品定位是 AI 辅助训练系统，不是在线判题系统。
- 学生通常已能在本地或 OpenJudge 运行代码，核心需求是理解错因、边界和下一步自查。
- 站内运行会引入不受信代码隔离、编译资源、超时、内存、并发、输出比对、滥用防护和成本监控。
- 没有标准程序、可靠测试集或老师确认输出时，单纯运行 AI 生成用例仍不能证明满分。

后续如果重新启动沙箱，应先做供应商或隔离方案 PoC，而不是直接自建：

- 使用托管沙箱 / Judge 服务验证安全边界、语言版本和资源限制。
- 只对老师确认过的自测或标准程序对拍开放更高可靠性等级。
- 学生端仍不得把运行结果包装成 AC 或满分证明。

因此，近期继续通过 AI 自测用例 + 学生自然追问承接运行反馈；真实代码执行保留为后续明确需求，不作为当前计划阻塞项。
