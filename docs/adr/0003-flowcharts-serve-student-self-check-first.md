# 流程图先服务学生自查

流程图功能第一版只服务学生的自己提交场景，展示大模型对题目的解题流程，包括读入、处理、判断或循环、输出等步骤。它不是学生程序的控制流图，也不展示完整 C++ 参考代码。

实现上复用学生提示链路：AI 返回结构化 `solution_flowchart`，服务端把节点和连线格式化成 Mermaid flowchart，学生详情页按需加载 Mermaid 渲染。流程图只随新提交生成，历史学生提示没有该字段时继续正常展示，不补生成、不新增迁移任务。

它不承担老师备课、复杂算法动画或完整可视化 IDE 职责。学生端仍遵守“不返回完整 main、完整可提交程序或参考程序”的边界。
