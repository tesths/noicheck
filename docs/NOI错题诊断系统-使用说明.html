1. 这是什么

这是一个帮学生练编程题、帮老师看作业的网站。

  • 学生：提交代码后，可以拿到“提示”，不会直接看到正确答案。
  • 老师：可以管理自己的学生，查看学生提交，并看到完整分析和参考程序。

打开方式：用浏览器访问

https://noi.bbbypw.online/

1.1 界面说明

当前界面已经统一为棕色主题，按钮、输入框、表格和提示状态都使用同一套组件样式。电脑和手机浏览器都可以使用，实际页面以线上版本为准。

3. 学生怎么用

3.1 登录

  1. 打开网站
  2. 点「学生登录」
  3. 输入老师给你的用户名和密码
  4. 进入「我的提交」

3.2 提交作业

点「新建提交」或「选择提交流程」，有两种方式：

方式一：自己提交

适合先自己检查。

  1. 点「自己提交」
  2. 粘贴题目链接
  3. 粘贴 C++ 代码
  4. 点「提交并获取 AI 提示」
  5. 稍等一会儿，查看提示

说明：

  • 这里只会给提示，不会直接给正确答案
  • 提示生成后，可以点「继续追问」再问和这道题相关的问题

方式二：提交给老师

适合交给老师批阅。

  1. 点「提交给老师」
  2. 粘贴题目链接
  3. 粘贴 C++ 代码
  4. 点「提交给老师」

说明：

  • 学生端只能看到处理状态
  • 完整分析和正确程序，只有老师能看

3.3 查看薄弱点行动

「我的提交」会根据自己提交产生的 AI 自查标签，汇总重复出现的知识点和错因。

  • 出现 2 次以上会标为「重点练习」
  • 单次出现会标为「观察中」
  • 可以点对应证据题，回到自查路线和 AI 自测用例继续复盘

3.4 学生端常见提示

状态意思
排队中 / 处理中系统正在处理，请稍等后刷新
成功结果已经出来了
失败没成功，可刷新后再试，或告诉老师

4. 老师怎么用

4.1 登录

  1. 打开网站
  2. 点「教师登录」
  3. 用户名填 pw
  4. 密码填 123456
  5. 进入后台

4.2 先创建学生

  1. 点「学生管理」
  2. 填写：
    • 学生用户名
    • 真实姓名
    • 初始密码
  3. 点「保存学生」
  4. 如果要一次创建多个学生，也可以在「批量导入学生」里粘贴多行 学生用户名,真实姓名,初始密码
  5. 把用户名和密码发给学生

之后还可以：

  • 重置密码
  • 停用 / 启用学生
  • 删除学生
  • 查看某个学生的全部提交

4.3 查看学生提交

  1. 点「提交列表」
  2. 可以看到自己学生的提交
  3. 点「查看详情」看完整内容
  4. 需要时点「学生界面」从学生视角查看

老师详情里通常能看到：

  • 题目
  • 学生代码
  • 学生提示
  • 老师完整诊断
  • 参考程序

4.4 查看任务健康

老师后台有「任务健康」，可以按抓题、学生提示、老师诊断查看失败和处理中任务，并打开对应提交详情排查。

4.5 系统设置

老师后台有「系统设置」，可以：

  • 切换 AI 模型
  • 修改老师 / 学生提示词

一般保持默认即可。

6. 常见问题

Q：我是新老师，为什么学生列表是空的？ 正常。你只能看到自己创建的学生，先去「学生管理」新建。

Q：为什么看不到其他老师的学生？ 系统按老师分开管理，每位老师只看自己的班级。

Q：学生为什么看不到正确答案？ 这是设计如此。学生只看提示，正确答案给老师看。

Q：提交后一直在处理中怎么办？ 先等几十秒，再刷新页面。如果一直失败，告诉老师或联系我们。

Q：创建学生时提示用户名被占用？ 换一个用户名再试。

Q：忘记学生密码怎么办？ 老师在「学生管理」里重置密码。

Q：想再开一个老师账号怎么办？ 请加我们微信联系获取。

Q：DeepSeek 的 Key 要自己填吗？ 普通老师和学生不用填。 如果是网站维护人员需要更换 AI 密钥，请直接联系我们协助配置。

7. 使用小提示
